# История версий

## 0.1.0 — первая версия

- Личные миры, которые создаются на работающем сервере: плоский, пустота, обычный, копия сида.
- Свой генератор плоского мира: пресеты, свои слои, сетка по чанкам.
- Роли: владелец, админ, строитель, гость; список доступа, запросы на вход, кик и бан.
- Ванильные команды для владельца и админов, действующие только внутри мира.
- Свои время, погода, правила игры и граница у каждого мира.
- Раздельные инвентари основного и личных миров (с Curios).
- Защита: блокировка порталов, переноса сущностей, выхода команд в другие миры, командных блоков.
- Автовыгрузка пустых миров, загрузка при входе и при перезаходе на сервер.
- Пересоздание, удаление и передача мира.
- Все тексты на русском в `messages.json`.

## Планы

- Меню-сундук `/pw menu` со всеми настройками.
- Отдельный чат мира.
- Лимиты сущностей против лагов.
- Экспорт постройки в схематику (`.nbt` / `.litematic`).
- Бэкапы и откат мира к снимку.
