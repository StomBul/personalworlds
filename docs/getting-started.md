# Быстрый старт
{: .no_toc }

От создания мира до совместной стройки.
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

## 1. Создайте мир

```text
/pw create
```

В чате появятся кнопки с типами мира и пресетами плоского мира. Нажмите нужную или введите
команду сразу:

| Команда | Что получится |
|---|---|
| `/pw create flat` | плоский мир: трава, под ней земля и камень |
| `/pw create flat blueprint` | плоский «чертёж»: белый бетон с серой сеткой по чанкам |
| `/pw create void` | пустота с маленькой платформой |
| `/pw create normal` | обычный мир со своим рельефом |
| `/pw create seed` | та же местность, что в основном мире, но без чужих построек |

Не знаете, что выбрать? Берите `blueprint`: сетка помогает размечать постройку.
Все варианты описаны в разделе [Типы миров](world-types).

После создания вы сразу окажетесь в своём мире.

{: .tip }
Из основного мира телепорт срабатывает через **3 секунды**: стойте на месте и не получайте урон.
Это защита от побега из боя. В креативе задержки нет.

## 2. Стройте

В своём мире вы **владелец**:

- у вас **креатив**;
- работают команды `/gamemode`, `/time`, `/weather`, `/give`, `/fill`, `/setblock`, `/clone`,
  `/summon` и другие ([полный список](roles#команды-админа-мира));
- всегда полдень, нет дождя, мобы сами не появляются, огонь не распространяется.

Всё это меняется в настройках:

```text
/pw setting
```

## 3. Вернитесь в выживание

```text
/pw leave
```

Вы окажетесь ровно там, откуда ушли, со своими вещами, опытом и здоровьем.

{: .important }
В личных мирах у вас **другой инвентарь**. Не пугайтесь, что вещи пропали при входе: они ждут вас
в основном мире. А вещи из креатива останутся в личных мирах до следующего захода.

Обратно в свой мир:

```text
/pw home
```

Вы появитесь там, где стояли в прошлый раз.

## 4. Позовите друзей

**Дать доступ самому:**

```text
/pw access add Steve builder
```

| Роль | Что может |
|---|---|
| `builder` — строитель | строить и ломать |
| `guest` — гость | только ходить и смотреть |
| `admin` — админ | строить, пользоваться командами, пускать других |

**Друг просит сам:**

```text
/pw request Alex
```

Владелец получит сообщение с кнопками **[Пустить гостем]**, **[Пустить строителем]**, **[Отклонить]**.

**Зайти к другу:**

```text
/pw visit Alex
```

Список всех миров, куда вас пустили, с кнопками **[Войти]**:

```text
/pw list
```

## Что ещё полезно знать

- Вышли с сервера в личном мире — при следующем входе окажетесь там же.
- Умерли в личном мире — возродитесь на его точке появления, вещи останутся при вас.
- Кровать в личном мире не ставит точку возрождения.
- Порталы в личных мирах не работают.
- Справка с кликабельными командами — просто `/pw`.
