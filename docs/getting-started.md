# Первые шаги
{: .no_toc }

Короткий гайд для игроков: от создания мира до совместной стройки.
{: .fs-6 .fw-300 }

1. TOC
{:toc}

---

## 1. Создайте мир

Напишите в чат:

```text
/pw create
```

Мод покажет кнопки с типами мира. Нажмите нужную или введите команду сразу:

| Команда | Мир |
|---|---|
| `/pw create flat` | плоский (пресет «Классический») |
| `/pw create flat blueprint` | плоский «чертёж» с сеткой по чанкам |
| `/pw create void` | пустота с маленькой платформой |
| `/pw create normal` | обычная генерация со случайным сидом |
| `/pw create seed` | та же местность, что в основном мире |

Подробнее про каждый тип и про свои слои — в разделе [Типы миров](world-types).

После создания вы сразу переместитесь в свой мир.

{: .tip }
Из основного мира телепорт срабатывает через **3 секунды**. Не двигайтесь и не получайте урон,
иначе он отменится. В креативе и внутри личных миров задержки нет.

## 2. Стройте

В своём мире вы **владелец**:

- по умолчанию у вас **креатив**;
- работают команды `/gamemode`, `/time`, `/weather`, `/give`, `/fill`, `/setblock`, `/clone`,
  `/summon` и другие (полный список — в разделе [Доступ и роли](roles#команды-админа-мира));
- все они действуют **только в вашем мире**.

В новом мире всегда полдень, нет смены погоды, мобы не появляются, огонь не распространяется,
вещи при смерти не выпадают. Всё это можно поменять в [настройках](settings).

## 3. Вернитесь в выживание

```text
/pw leave
```

Вы окажетесь ровно там, откуда ушли, со своим обычным инвентарём, опытом и здоровьем.

{: .important }
**Инвентари разделены.** В личных мирах у вас отдельный инвентарь, один на все личные миры.
Вещи из креатива нельзя вынести в выживание, а вещи из выживания не пропадают, пока вы строите.

Обратно в свой мир:

```text
/pw home
```

Мод запоминает, где вы стояли в каждом личном мире, и вернёт вас на то же место.

## 4. Позовите друзей

**Дать доступ самому:**

```text
/pw access add Steve builder
```

Роли: `builder` — строитель, `guest` — гость (только смотрит), `admin` — помощник с командами.
Подробнее — в разделе [Доступ и роли](roles).

**Друг просит сам:**

```text
/pw request Alex
```

Владелец мира получит сообщение с кнопками **[Пустить гостем]**, **[Пустить строителем]** и
**[Отклонить]**. Если владелец не в сети, запрос подождёт 2 минуты.

**Зайти к другу:**

```text
/pw visit Alex
```

Все миры, куда у вас есть доступ, с кнопками входа:

```text
/pw list
```

## Полезно знать

- Если выйти с сервера, стоя в личном мире, при следующем входе вы окажетесь там же.
- Если умереть в личном мире, вы возродитесь на его точке появления.
- В личном мире нельзя поставить точку возрождения кроватью.
- Порталы в личных мирах не работают.
- Справка с кликабельными командами — просто `/pw`.
