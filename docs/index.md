# Personal Worlds
{: .fs-9 }

Личный мир для каждого игрока прямо на сервере: проектируйте постройки в креативе,
зовите друзей и не выходите из игры.
{: .fs-6 .fw-300 }

[Установка](installation){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[Первые шаги](getting-started){: .btn .fs-5 .mb-4 .mb-md-0 }

## Что это

**Personal Worlds** — серверный мод для **NeoForge 1.21.1**. Каждый игрок может создать себе
один мир, в котором он администратор. Права работают только в этом мире: в основном
мире выживания игрок остаётся обычным игроком.

Мод сделан для того, чтобы игроки проектировали свои проекты, не выходя с сервера:
строили макет в креативе, пробовали варианты и звали друзей помогать.

{: .important }
Мод **только серверный**. Игрокам ничего ставить не нужно, всё управление идёт командами
и кнопками в чате.

## Возможности

| | |
|---|---|
| 🌍 **Свой мир у каждого** | Миры создаются прямо на работающем сервере, без перезапуска. |
| 🧱 **Свой плоский генератор** | Не ломается от модов генерации (Tectonic, Terralith, увеличенная высота мира). Пресеты, свои слои, сетка по чанкам. |
| 🌌 **Четыре типа мира** | Плоский, пустота, обычный со случайным сидом, копия сида основного мира. |
| 👑 **Права только в своём мире** | `time`, `weather`, `gamerule`, `gamemode`, `give`, `fill`, `setblock`, `clone`, `summon` и другие действуют только внутри мира. |
| 👥 **Друзья и роли** | Владелец, админ, строитель, гость. Список доступа, запросы на вход с кнопками, кик и бан. |
| 🎒 **Раздельные инвентари** | Вещи из креатива не попадут в выживание, вещи из выживания — в креатив. |
| 🛡️ **Защита основного мира** | Никаких порталов, переноса предметов и мобов между мирами, выхода команд за пределы мира. |
| 💤 **Экономия ресурсов** | Пустые миры выгружаются из памяти и загружаются при входе. |

## Как это выглядит в игре

```text
/pw create flat blueprint      → создать плоский мир-«чертёж» с сеткой
/pw home                       → перейти в свой мир
/pw access add Steve builder   → пустить друга строителем
/pw leave                      → вернуться в выживание, туда, откуда ушли
```
