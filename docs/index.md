# Личные миры
{: .fs-9 }

У каждого игрока сервера может быть свой мир для проектов. В нём вы администратор,
можно строить в креативе и звать друзей. Здесь собраны все команды и объяснено, как это работает.
{: .fs-6 .fw-300 }

[Все команды](commands){: .btn .fs-5 .mb-4 .mb-md-0 }

## Шпаргалка

| Хочу… | Команда |
|---|---|
| создать свой мир | `/pw create` |
| попасть в свой мир | `/pw home` |
| вернуться в выживание | `/pw leave` |
| зайти к другу | `/pw visit <ник>` |
| попросить доступ к чужому миру | `/pw request <ник>` |
| посмотреть, куда я могу зайти | `/pw list` |
| пустить друга строить | `/pw access add <ник> builder` |
| пустить друга посмотреть | `/pw access add <ник> guest` |
| сделать друга помощником с командами | `/pw role <ник> admin` |
| выгнать игрока из своего мира | `/pw kick <ник>` |
| открыть настройки мира | `/pw setting` |
| поставить точку появления | `/pw setspawn` |
| изменить размер мира | `/pw border <размер>` |
| сменить тип мира (всё удалится) | `/pw reset <тип>` |
| справка прямо в игре | `/pw` |

{: .tip }
Почти все сообщения мода кликабельные. Нажимайте на кнопки **[Войти]**, **[вкл]**, **[Подтвердить]**
в чате вместо того, чтобы набирать команды.

## Главное, что нужно знать

- **Один мир на игрока.** Тип мира выбирается при создании: плоский, пустота, обычный или копия
  местности основного мира. [Подробнее о типах](world-types).
- **Инвентари разные.** В личных мирах у вас отдельный инвентарь. Вещи из креатива не попадут в
  выживание, вещи из выживания не пропадут. [Как это устроено](how-it-works#инвентари).
- **Права только у себя.** В своём мире вы можете пользоваться `/gamemode`, `/time`, `/give`,
  `/fill` и другими командами, но они действуют только внутри вашего мира. [Роли и права](roles).
- **Возврат на место.** `/pw leave` возвращает туда, откуда вы ушли, а `/pw home` — туда, где вы
  стояли в своём мире.
