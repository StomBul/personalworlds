# Защита основного мира
{: .no_toc }

## Раздельные инвентари

У каждого игрока два набора вещей и состояния:

| | Основной мир | Личные миры |
|---|---|---|
| Инвентарь и броня | свой | свой (один на все личные миры) |
| Эндер-сундук | свой | свой |
| Слоты Curios | свои | свои |
| Опыт | свой | свой |
| Здоровье, голод, эффекты | свои | свои |
| Режим игры | выживание | по роли в мире |

При входе в личный мир состояние основного мира сохраняется на диск, при выходе — возвращается.
Обмен происходит при **любом** способе перемещения, даже если оператор перенёс игрока через `/tp`.

{: .note }
Если сервер упадёт, пока игрок в личном мире, при следующем входе мод разберётся, какое состояние
правильное, и не даст размножить вещи.

## Что не может пересечь границу

- **Предметы, мобы, вагонетки, лодки, поезда Create** не переходят между личными и основными мирами.
- **Порталы.** В личных мирах не создаются порталы в Незер. Любой другой телепорт из личного мира,
  например предметы из модов или порталы в Энд, вместо этого вернёт игрока в точку выхода.
- **Carry On.** Нельзя телепортироваться, неся сундук или существо в руках.
- **Точка возрождения.** Кровати и якоря в личных мирах не ставят точку возрождения.
  После смерти в личном мире игрок возрождается на его точке появления.
- **Вход в личные миры** возможен только командами `/pw home` и `/pw visit` (и операторам).

## Ограничения команд

Владелец и админы личного мира получают доступ к ванильным командам, но не становятся операторами
сервера:

- команды работают, только пока игрок стоит в своём мире;
- `@a`, `@e` и ники находят только сущности этого мира — `/give`, `/tp`, `/kill` не достанут
  игроков в выживании;
- `/time`, `/weather`, `/gamerule` меняют только этот мир;
- `execute in` и аргументы с другим измерением запрещены (`clone from minecraft:overworld` и т. п.);
- правила игры, влияющие на весь сервер, заблокированы;
- граница меняется только через `/pw border` в пределах лимита.

## Командные блоки и компьютеры

- **Командные блоки** и вагонетки с ними в личных мирах по умолчанию не работают
  (настройка `allowCommandBlocks`).
- Если их включить, они тоже ограничены своим миром и могут выполнять только команды из списка
  `nonPlayerCommands`.
- Это же ограничение действует на **командные компьютеры CC:Tweaked**.

## Гости

Гость в чужом мире не может ломать и ставить блоки, нажимать кнопки, открывать сундуки,
использовать предметы и бить существ. По умолчанию гости в режиме приключения.

## PvP

По умолчанию в личных мирах игроки не могут наносить урон друг другу. Включается в
[настройках](settings): `/pw setting pvp on`.

## Что пока не разделено

{: .note }
Достижения и статистика общие: достижение, полученное в креативе, засчитается игроку.
