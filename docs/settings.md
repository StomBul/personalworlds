## Меню настроек

```text
/pw setting
```

Покажет все настройки с текущими значениями и кнопками **[вкл]** / **[выкл]**. Менять настройки
могут владелец и админы мира.

Изменить одну настройку командой:

```text
/pw setting <настройка> <значение>
```

Для включения подходят `on`, `true`, `вкл`, `да`, `1`, для выключения — `off`, `false`, `выкл`, `нет`, `0`.

## Список настроек

| Настройка | Значения | По умолчанию | Что делает |
|---|---|---|---|
| `name` | текст до 32 символов | ник владельца | название мира в списках (только владелец) |
| `builder_mode` | `creative` `survival` `adventure` `spectator` | `creative` | режим игры для владельца, админов и строителей |
| `guest_mode` | `creative` `survival` `adventure` `spectator` | `adventure` | режим игры для гостей |
| `offline_access` | вкл / выкл | вкл | можно ли заходить без владельца (только владелец) |
| `pvp` | вкл / выкл | выкл | урон между игроками |
| `daylight` | вкл / выкл | выкл | смена дня и ночи |
| `weather_cycle` | вкл / выкл | выкл | смена погоды |
| `mobs` | вкл / выкл | выкл | естественное появление мобов |
| `fire` | вкл / выкл | выкл | распространение огня |
| `fall_damage` | вкл / выкл | вкл | урон от падения |
| `keep_inventory` | вкл / выкл | вкл | вещи остаются после смерти |
| `mob_griefing` | вкл / выкл | выкл | криперы, эндермены и т. п. ломают блоки |

## Время и погода

```text
/pw setting time <day|noon|night|midnight|число>
/pw setting weather <clear|rain|thunder>
```

| Значение | Время |
|---|---|
| `day` | утро (1000) |
| `noon` | полдень (6000) |
| `night` | вечер (13000) |
| `midnight` | полночь (18000) |

Чтобы время и погода не сбивались, оставьте выключенными `daylight` и `weather_cycle`.

{: .tip }
Владелец и админы могут пользоваться и ванильными `/time set` и `/weather`. В личном мире они
меняют только этот мир.

## Точка появления

```text
/pw setspawn
```

Встаньте на нужное место и выполните команду. Сюда попадают игроки при первом входе в мир и
после смерти. Если игрок уже был в мире, `/pw home` и `/pw visit` вернут его на последнее место.

## Граница мира

```text
/pw border           → текущий размер и лимит
/pw border <размер>  → изменить
```

Размер — сторона квадрата в блоках, центр в точке (0, 0). Лимит задаёт админ сервера.

## Правила игры

Владелец и админы могут менять правила игры ванильной командой `/gamerule`. У каждого личного
мира свои правила, на основной мир они не влияют. Например:

```text
/gamerule doTileDrops false
/gamerule playersSleepingPercentage 0
```

Правила, которые влияют на весь сервер или на нагрузку (`randomTickSpeed`, `spawnChunkRadius`
и др.), в личных мирах заблокированы.

## Что сохраняется при пересоздании мира

При `/pw reset` сохраняются доступы, роли, баны, настройки из этой страницы и правила игры.
Пропадают постройки, точка появления и время суток.
