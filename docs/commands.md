## Свой мир

| Команда | Описание |
|---|---|
| `/pw` | справка с кликабельными командами |
| `/pw create` | меню выбора типа мира |
| `/pw create flat [пресет]` | плоский мир, [пресеты](world-types#пресеты): `classic` `blueprint` `grass_grid` `stone` `sand` `snow` `thin` |
| `/pw create flat custom <слои>` | плоский мир со своими слоями, например `bedrock,3*dirt,grass_block` |
| `/pw create void` | пустота |
| `/pw create normal` | обычный мир со случайным сидом |
| `/pw create seed` | местность основного мира |
| `/pw home` | перейти в свой мир |
| `/pw info [ник]` | тип, размер, участники, загружен ли мир |

## Перемещение

| Команда | Описание |
|---|---|
| `/pw home` | в свой мир, на место, где стояли в прошлый раз |
| `/pw visit <ник>` | в мир игрока (нужен доступ) |
| `/pw leave` | в основной мир, туда, откуда ушли |
| `/pw list` | все миры, куда вас пустили, с кнопками **[Войти]** |

Из основного мира в выживании телепорт происходит через 3 секунды. Если сдвинуться или получить
урон, он отменится. Внутри личных миров и в креативе задержки нет.

## Доступ

| Команда | Кто | Описание |
|---|---|---|
| `/pw request <ник>` | все | попросить доступ в мир игрока |
| `/pw accept <ник> [роль]` | админ+ | принять запрос (без роли — гостем) |
| `/pw deny <ник>` | админ+ | отклонить запрос |
| `/pw access` | админ+ | список участников с кнопками |
| `/pw access add <ник> [роль]` | админ+ | дать доступ (без роли — строителем) |
| `/pw access remove <ник>` | админ+ | забрать доступ |
| `/pw role <ник> <admin\|builder\|guest>` | админ+ | сменить роль |
| `/pw kick <ник>` | админ+ | выгнать в основной мир |
| `/pw ban <ник>` | админ+ | заблокировать в мире |
| `/pw unban <ник>` | админ+ | разблокировать |

«Админ+» — админ мира или владелец. Роль `admin` выдаёт только владелец. Подробнее — в разделе
[Доступ и роли](roles).

## Настройки

| Команда | Кто | Описание |
|---|---|---|
| `/pw setting` | админ+ | меню настроек с кнопками |
| `/pw setting <настройка> <значение>` | админ+ | изменить настройку, [список](settings#все-настройки) |
| `/pw setting time <day\|noon\|night\|midnight\|число>` | админ+ | время суток |
| `/pw setting weather <clear\|rain\|thunder>` | админ+ | погода |
| `/pw setspawn` | админ+ | точка появления на вашем месте |
| `/pw border [размер]` | админ+ | показать или изменить размер мира |

## Пересоздание, удаление, передача

Только для владельца. Каждое действие нужно подтвердить кнопкой **[Подтвердить]** или командой
`/pw confirm` в течение 30 секунд.

| Команда | Описание |
|---|---|
| `/pw reset` | меню выбора нового типа |
| `/pw reset <тип> [пресет]` | пересоздать мир с новым типом (участники и настройки сохранятся) |
| `/pw delete` | удалить мир навсегда |
| `/pw transfer <ник>` | отдать мир другому игроку (у него не должно быть своего мира); вы станете в нём админом |
| `/pw confirm` | подтвердить последнее действие |

{: .warning }
`reset` и `delete` удаляют все постройки **безвозвратно**. Пересоздавать мир можно не чаще
раза в 10 минут.

## Ванильные команды в своём мире

Владельцу и админам мира в их мире доступны `/time`, `/weather`, `/gamerule`, `/setworldspawn`,
`/gamemode`, `/tp`, `/effect`, `/clear`, `/give`, `/fill`, `/setblock`, `/clone`, `/place`,
`/fillbiome`, `/summon`, `/kill`, `/data`, `/item`, `/particle`, `/playsound`, `/title`, `/tellraw`.
Ограничения описаны в разделе [Доступ и роли](roles#команды-админа-мира).

Несколько примеров:

```text
/gamemode spectator                       ← облететь постройку
/fill ~-10 63 ~-10 ~10 63 ~10 stone       ← залить площадку
/clone 0 64 0 20 80 20 100 64 0           ← скопировать постройку
/give @s minecraft:light 64               ← невидимые источники света
/tp @a ~ ~ ~                              ← собрать всех в мире к себе
/time set 18000                           ← посмотреть, как постройка выглядит ночью
```
