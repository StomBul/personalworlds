## Основные

| Команда | Кто | Описание |
|---|---|---|
| `/pw` или `/pw help` | все | справка с кликабельными командами |
| `/pw create` | все | меню выбора типа мира |
| `/pw create flat [пресет]` | все | плоский мир, см. [пресеты](world-types#пресеты) |
| `/pw create flat custom <слои>` | все | плоский мир со своими слоями |
| `/pw create void` | все | пустота |
| `/pw create normal` | все | обычная генерация, случайный сид |
| `/pw create seed` | все | генерация и сид основного мира |
| `/pw home` | владелец | перейти в свой мир |
| `/pw visit <ник>` | участник | перейти в мир игрока |
| `/pw leave` | все | вернуться в основной мир, туда, откуда ушли |
| `/pw list` | все | миры, куда у вас есть доступ, с кнопками входа |
| `/pw info [ник]` | все | тип, граница, число участников, загружен ли мир |

## Доступ

| Команда | Кто | Описание |
|---|---|---|
| `/pw request <ник>` | все | попросить доступ в мир игрока |
| `/pw accept <ник> [admin\|builder\|guest]` | админ+ | принять запрос (по умолчанию гостем) |
| `/pw deny <ник>` | админ+ | отклонить запрос |
| `/pw access` | админ+ | список доступа с кнопками |
| `/pw access add <ник> [роль]` | админ+ | дать доступ (по умолчанию строителем) |
| `/pw access remove <ник>` | админ+ | забрать доступ |
| `/pw role <ник> <роль>` | админ+ | сменить роль участника |
| `/pw kick <ник>` | админ+ | выгнать из мира |
| `/pw ban <ник>` | админ+ | заблокировать |
| `/pw unban <ник>` | админ+ | разблокировать |

Роль `admin` может выдавать только владелец. Подробнее — в разделе [Доступ и роли](roles).

## Настройки

| Команда | Кто | Описание |
|---|---|---|
| `/pw setting` | админ+ | меню настроек с кнопками |
| `/pw setting <настройка> <значение>` | админ+ | изменить настройку, см. [список](settings#список-настроек) |
| `/pw setspawn` | админ+ | точка появления там, где вы стоите |
| `/pw border [размер]` | админ+ | показать или изменить границу мира |

## Пересоздание, удаление, передача

Эти команды есть только у владельца. Каждую нужно подтвердить кнопкой **[Подтвердить]** или
командой `/pw confirm` в течение 30 секунд.

| Команда | Описание |
|---|---|
| `/pw reset` | меню выбора нового типа |
| `/pw reset <тип> [пресет]` | пересоздать мир с новым типом; доступы и настройки сохранятся |
| `/pw delete` | удалить мир навсегда |
| `/pw transfer <ник>` | передать мир другому игроку, у которого нет своего мира; вы станете в нём админом |
| `/pw confirm` | подтвердить последнее действие |

{: .warning }
При `reset` и `delete` все постройки удаляются безвозвратно. Пересоздавать мир можно не чаще
раза в 10 минут.

## Администратор сервера

Нужен уровень оператора 2+.

| Команда | Описание |
|---|---|
| `/pw admin list` | все личные миры и их состояние |
| `/pw admin limit <ник> <размер>` | поднять игроку лимит границы мира |
| `/pw admin unload <ник>` | выгрузить мир игрока (все внутри вернутся в основной мир) |
| `/pw admin delete <ник>` | удалить мир игрока без подтверждения |
| `/pw admin reload` | перечитать `messages.json` и `flat_presets.json` |

Операторы могут зайти в любой мир через `/pw visit <ник>` и управлять им как владелец.
