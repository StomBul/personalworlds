## Спроектировать дом перед стройкой в выживании

1. Создайте мир с сеткой, по ней удобно считать блоки:
   ```text
   /pw create flat blueprint
   ```
2. Стройте в креативе. Для заливки площадок пригодятся `/fill`, для копирования частей — `/clone`.
3. Посмотрите на постройку со стороны:
   ```text
   /gamemode spectator
   ```
   Вернуться: `/gamemode creative`.
4. Оцените, как она выглядит ночью:
   ```text
   /pw setting time midnight
   ```
5. Вернитесь в выживание (`/pw leave`) и стройте по макету. Сетка по чанкам поможет перенести
   размеры один в один.

## Примерить постройку на реальную местность

Хотите поставить замок на конкретную гору в выживании?

1. Создайте мир с той же местностью:
   ```text
   /pw create seed
   ```
2. Запомните координаты горы в основном мире и перейдите туда в личном:
   ```text
   /tp @s <x> <y> <z>
   ```
3. Стройте на том же месте. Рельеф совпадает блок в блок, но чужих построек нет.

{: .note }
Для удалённых мест увеличьте границу мира: `/pw border 2048`. Граница строится от точки (0, 0),
поэтому координаты дальше 1024 от центра в мир не попадут. Если нужно дальше, попросите
администрацию поднять лимит.

## Строить вместе с другом

1. Дайте другу доступ строителя:
   ```text
   /pw access add Steve builder
   ```
2. Он зайдёт командой `/pw visit <ваш ник>` или кнопкой **[Войти]** в сообщении.
3. Если другу тоже нужны команды (`/fill`, `/time` и т. д.), сделайте его админом:
   ```text
   /pw role Steve admin
   ```
4. Чтобы друг мог строить, даже когда вас нет в сети, ничего делать не нужно: это включено
   по умолчанию.

## Показать проект, но не дать его испортить

1. Пустите игроков гостями:
   ```text
   /pw access add Alex guest
   ```
2. Гости ходят в режиме приключения и ничего не могут сломать или открыть.
3. Хотите, чтобы гости облетали постройку свободно? Включите для них режим наблюдателя:
   ```text
   /pw setting guest_mode spectator
   ```
4. Поставьте точку появления у входа:
   ```text
   /pw setspawn
   ```

## Закрыть мир, пока вас нет

```text
/pw setting offline_access off
```

Без вас в мир не зайдёт никто, а когда вы выйдете с сервера, все участники вернутся в основной мир.

## Протестировать ферму или механизм

1. Пустота подходит для редстоуна, а плоский мир — для ферм на земле:
   ```text
   /pw create void
   ```
2. Для мобных ферм включите появление мобов и смену дня:
   ```text
   /pw setting mobs on
   /pw setting daylight on
   ```
3. Для честной проверки на выживании переключите режим:
   ```text
   /pw setting builder_mode survival
   ```

## Начать заново

```text
/pw reset flat classic
/pw confirm
```

Постройки удалятся, а участники, роли и настройки останутся. Пересоздавать можно раз в 10 минут.

## Отдать мир другу

```text
/pw transfer Steve
/pw confirm
```

Мир станет миром Steve (у него не должно быть своего), а вы останетесь в нём админом.
После этого можно создать себе новый мир.
