## Требования

| | |
|---|---|
| Minecraft | **1.21.1** |
| Загрузчик | **NeoForge 21.1** и новее |
| Java | 21 |
| Сторона | только **сервер** |

Обязательных зависимостей нет. Если на сервере стоят **Curios** или **Carry On**, мод подхватит их
сам: слоты Curios тоже разделяются между мирами, а с блоком в руках Carry On телепорт запрещён.

## Установка на сервер

1. Скачайте `personalworlds-<версия>.jar` из раздела **Releases**.
2. Положите файл в папку `mods` сервера.
3. Запустите сервер. При первом запуске появятся файлы настроек:

```text
config/
├── personalworlds-common.toml        ← лимиты, задержки, списки команд
└── personalworlds/
    ├── messages.json                 ← все тексты мода (на русском)
    └── flat_presets.json             ← пресеты плоского мира
```

4. По желанию поправьте настройки и перезапустите сервер. Описание всех параметров — в разделе
   [Администрирование](admin).

{: .note }
Игрокам ставить мод не нужно. Клиенты подключаются к серверу как обычно, команды `/pw`
сами появятся у них в подсказках.

## Обновление

Замените `.jar` в папке `mods` и перезапустите сервер. Миры, доступы и инвентари хранятся в папке
мира и не теряются при обновлении. Новые тексты сообщений дописываются в `messages.json`
автоматически, ваши правки остаются.

## Удаление

{: .warning }
Перед удалением мода попросите игроков выйти из личных миров командой `/pw leave`.
Пока игрок в личном мире, его вещи из выживания хранятся у мода. Если удалить мод в этот момент,
игрок появится в основном мире с инвентарём из креатива.

Данные мода лежат в папке мира:

```text
world/
├── personalworlds/              ← список миров, доступы, инвентари игроков
└── dimensions/personalworlds/   ← сами личные миры
```

## Сборка из исходников

```bash
./gradlew build
```

Готовый файл появится в `build/libs/`. Автотест проходит весь путь игрока: создание мира,
обмен инвентаря, права админа, гость, выгрузка и загрузка, перезаход, смерть, разные типы миров.

```bash
./gradlew runGameTestServer
```
