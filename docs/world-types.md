## Обзор

| Тип | Команда | Высота мира | Для чего |
|---|---|---|---|
| **Плоский** | `/pw create flat [пресет]` | −64…320 | макеты, планировка, большинство проектов |
| **Пустота** | `/pw create void` | −64…320 | постройки «в воздухе», схемы, редстоун |
| **Обычный** | `/pw create normal` | как в основном мире | проекты на природном рельефе |
| **Копия сида** | `/pw create seed` | как в основном мире | примерка постройки на реальную местность сервера |

{: .note }
У каждого игрока один мир. Сменить тип можно командой `/pw reset <тип>`, но постройки при этом
пропадут. Подробнее — в разделе [Все команды](commands#пересоздание-удаление-передача).

## Плоский мир

У мода **свой генератор плоского мира**. Ванильный суперплоский мир на серверах с модами генерации
(Tectonic, Terralith, увеличенная высота мира) часто получается не плоским или со сдвинутой
поверхностью. Генератор Personal Worlds ставит слои по точным высотам и ни от чего не зависит:

- поверхность по умолчанию на **Y = 64**, как уровень моря в обычном мире;
- нет деревень, крепостей, пещер, деревьев, травы и руд;
- мобы при генерации не появляются;
- под нижним слоем пустота.

### Пресеты

| Пресет | Название | Слои (снизу вверх) |
|---|---|---|
| `classic` | Классический | бедрок, 58 камня, 4 земли, трава |
| `blueprint` | Чертёж: сетка по чанкам | бедрок, 62 камня, белый бетон + сетка из светло-серого бетона |
| `grass_grid` | Трава с сеткой по чанкам | как классический + сетка из блоков мха |
| `stone` | Камень | бедрок, 63 камня |
| `sand` | Пустыня | бедрок, 56 камня, 4 песчаника, 4 песка |
| `snow` | Снег | бедрок, 58 камня, 4 земли, снежный блок |
| `thin` | Тонкий (4 блока) | бедрок, 2 земли, трава |

```text
/pw create flat blueprint
```

{: .tip }
**Сетка** — линия другого блока по границам чанков на верхнем слое. По ней удобно размечать
постройку и потом переносить её в выживание по чанкам.

Админ сервера может добавить свои пресеты, см. [Администрирование](admin#пресеты-плоского-мира).

### Свои слои

```text
/pw create flat custom bedrock,10*stone,3*dirt,grass_block
```

Формат такой же, как у ванильного суперплоского мира:

- слои перечисляются **снизу вверх** через запятую;
- `N*блок` — N одинаковых слоёв подряд;
- `minecraft:` можно не писать, блоки из модов указываются полностью: `create:andesite_casing`;
- суммарная толщина по умолчанию не больше 384 блоков.

Верхний слой всё равно окажется на высоте Y = 63, а стоять вы будете на Y = 64.

## Пустота

Мир без блоков. На точке появления есть платформа 5×5 из гладкого камня на Y = 63.
Биом — «Пустота», без дождя и мобов.

## Обычный мир

Мир генерируется так же, как основной мир сервера, со всеми модами генерации, но со **случайным
сидом**. Рельеф будет другим, а биомы и стиль — те же.

{: .note }
Первый вход в обычный мир может занять пару секунд: сервер генерирует область вокруг точки
появления. Высота мира такая же, как в основном мире.

## Копия сида основного мира

Та же генерация и **тот же сид**, что у основного мира. Рельеф и биомы совпадают с выживанием,
но там нет построек игроков. Удобно, чтобы:

- примерить постройку на точно такую же местность;
- спланировать терраформинг;
- построить макет в креативе, а потом повторить его в выживании по тем же координатам.

## Граница мира

У каждого мира своя граница — квадрат с центром в точке (0, 0). По умолчанию **512×512 блоков**.

```text
/pw border          → текущий размер и лимит
/pw border 1024     → изменить
```

Игрок может выставить размер от 32 до 2048 блоков. Админ сервера может поднять лимит конкретному
игроку: `/pw admin limit <ник> <размер>`.
