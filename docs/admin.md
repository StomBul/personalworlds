## Файл настроек

`config/personalworlds-common.toml`. После изменения перезапустите сервер.

### Миры — `[worlds]`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `defaultBorderSize` | `512` | граница нового мира (сторона квадрата в блоках) |
| `maxBorderSize` | `2048` | максимальная граница, которую игрок может выставить сам |
| `minBorderSize` | `32` | минимальная граница |
| `autoUnloadMinutes` | `5` | через сколько минут без игроков мир выгружается из памяти; `0` — никогда |
| `resetCooldownMinutes` | `10` | задержка между пересозданиями мира |
| `flatSurfaceY` | `64` | высота поверхности плоского мира (первый блок воздуха) |
| `maxFlatThickness` | `384` | максимальная суммарная толщина слоёв |
| `buildDimensionType` | `personalworlds:build` | тип измерения для плоских и пустых миров |

### Телепорт — `[teleport]`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `warmupSeconds` | `3` | задержка телепорта из основного мира в выживании; `0` — без задержки |
| `requestTimeoutSeconds` | `120` | сколько действует запрос на вход |
| `kickOnOwnerLogout` | `true` | выгонять участников, когда владелец вышел, если в мире выключен `offline_access` |

### Права в личных мирах — `[permissions]`

| Параметр | Описание |
|---|---|
| `adminCommands` | ванильные и модовые команды, доступные владельцу и админам мира |
| `nonPlayerCommands` | команды для командных блоков и компьютеров в личных мирах |
| `blockedGameRules` | правила игры, которые нельзя менять в личных мирах |
| `allowCommandBlocks` | разрешить командные блоки в личных мирах (по умолчанию `false`) |

{: .warning }
Добавляйте в `adminCommands` только команды, которые безопасно давать обычным игрокам. Мод
ограничивает селекторы и измерения, но модовая команда может делать что-то за пределами мира
своими способами.

Пример: дополнительно разрешить `/spreadplayers`:

```toml
adminCommands = ["time", "weather", "gamerule", "setworldspawn", "gamemode", "tp", "teleport",
  "effect", "clear", "give", "fill", "setblock", "clone", "place", "fillbiome", "summon", "kill",
  "data", "item", "particle", "playsound", "title", "tellraw", "spreadplayers"]
```

{: .note }
`/difficulty` и `/worldborder` в список добавлять не нужно: они меняют **весь сервер**.
Границу личного мира меняют через `/pw border`.

## Тексты сообщений

`config/personalworlds/messages.json` — все тексты мода на русском. Формат:

```json
{
  "prefix": "&8[&bМиры&8] &r",
  "tp.left": "&aВы вернулись в основной мир. Инвентарь восстановлен.",
  "access.added": "&aИгрок &e{0}&a получил доступ к миру с ролью &f{1}&a."
}
```

- цвета и стили через `&`: `&a` зелёный, `&c` красный, `&e` жёлтый, `&l` жирный, `&r` сброс;
- `{0}`, `{1}` — подстановки (ник, роль, число и т. п.);
- новые ключи после обновления мода дописываются автоматически.

Применить без перезапуска: `/pw admin reload`.

## Пресеты плоского мира

`config/personalworlds/flat_presets.json`:

```json
{
  "classic": {
    "name": "Классический",
    "layers": "bedrock,58*stone,4*dirt,grass_block"
  },
  "blueprint": {
    "name": "Чертёж: сетка по чанкам",
    "layers": "bedrock,62*stone,white_concrete",
    "grid": "light_gray_concrete"
  }
}
```

- ключ (`classic`) — ID для команды `/pw create flat <ID>`;
- `name` — название в меню;
- `layers` — слои снизу вверх, `N*блок`;
- `grid` — необязательный блок сетки по границам чанков.

Пресет с ошибкой (например, неизвестный блок) пропускается, причина пишется в лог.
Применить без перезапуска: `/pw admin reload`.

## Где хранятся данные

```text
world/
├── personalworlds/
│   ├── worlds.dat               ← миры, владельцы, доступы, настройки, лимиты
│   └── players/<uuid>.dat       ← инвентари игроков, точки возврата
└── dimensions/personalworlds/
    └── w_<id>_<номер>/          ← сами миры (регионы, сущности)
```

{: .tip }
Для бэкапа сохраняйте обе папки вместе с основным миром.

Папки удалённых и пересозданных миров удаляются автоматически. Если сервер остановили раньше,
они удалятся при следующем запуске.

## Нагрузка на сервер

- Мир загружается, только когда в него кто-то заходит, и выгружается через `autoUnloadMinutes`
  минут после того, как все вышли.
- Спавн-чанки личных миров не держатся загруженными.
- Плоские и пустые миры генерируются почти мгновенно. Обычный мир и копия сида генерируются как
  основной мир, поэтому первый вход дольше.
- Проверить нагрузку: `/spark tickmonitor` или `/pw admin list`.

## Совместимость

| Мод | Статус |
|---|---|
| Curios | слоты разделяются вместе с инвентарём |
| Carry On | телепорт с блоком в руках запрещён |
| CC:Tweaked | командные компьютеры ограничены своим миром |
| Tectonic, Terralith, Lithostitched, Extended World Height | не влияют на плоские миры; обычный мир и копия сида используют их генерацию |
| Create | поезда и контрапции не переходят между мирами |
