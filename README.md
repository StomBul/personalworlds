# Personal Worlds (NeoForge 1.21.1)

Личные миры игроков на одном сервере. Каждый игрок создаёт себе мир, в котором он администратор,
пускает туда друзей и раздаёт им роли. Мод **только серверный**: игрокам ничего ставить не нужно.

📖 **Полный гайд — на сайте документации** (папка [`docs/`](docs/), публикуется через GitHub Pages).

## Установка

Положить `build/libs/personalworlds-0.1.0.jar` в папку `mods` сервера. Зависимостей нет
(Curios и Carry On подхватываются автоматически, если установлены).

## Команды игроков

| Команда | Что делает |
|---|---|
| `/pw` | справка с кликабельными командами |
| `/pw create` | меню выбора типа мира |
| `/pw create flat [пресет]` | плоский мир (пресеты: classic, blueprint, grass_grid, stone, sand, snow, thin) |
| `/pw create flat custom bedrock,3*dirt,grass_block` | плоский мир со своими слоями (снизу вверх) |
| `/pw create void` / `normal` / `seed` | пустота / обычная генерация со случайным сидом / с сидом основного мира |
| `/pw home` | в свой мир |
| `/pw leave` | вернуться в основной мир, туда, откуда ушли |
| `/pw visit <ник>` | в мир другого игрока |
| `/pw request <ник>` | попросить доступ (владелец получит кнопки «Пустить гостем / строителем / Отклонить») |
| `/pw list` | миры, куда у вас есть доступ |
| `/pw info [ник]` | информация о мире |

## Управление своим миром (владелец и админы мира)

| Команда | Что делает |
|---|---|
| `/pw access` | список доступа с кнопками |
| `/pw access add <ник> [admin\|builder\|guest]` | дать доступ (по умолчанию строитель) |
| `/pw access remove <ник>` | забрать доступ |
| `/pw role <ник> <роль>` | сменить роль |
| `/pw accept <ник> [роль]`, `/pw deny <ник>` | ответить на запрос |
| `/pw kick`, `/pw ban`, `/pw unban <ник>` | выгнать / заблокировать |
| `/pw setting` | меню настроек: режимы игры, вход без владельца, PvP, день/ночь, погода, мобы, огонь, урон от падения, keepInventory |
| `/pw setspawn` | точка появления в мире |
| `/pw border <размер>` | граница мира (до лимита сервера) |
| `/pw reset <тип>`, `/pw delete`, `/pw transfer <ник>` | пересоздать / удалить / передать мир (только владелец, с подтверждением) |

**Роли:** владелец (всё), админ (команды мира и доступ гостей/строителей), строитель (строит), гость (только смотрит).

**Ванильные команды админа мира** (список в конфиге, `adminCommands`): time, weather, gamerule,
gamemode, tp, effect, clear, give, fill, setblock, clone, place, fillbiome, summon, kill, data, item и др.
Они действуют только внутри его мира: `@a`/`@e`/ники находят только сущности этого мира,
`execute in` и аргументы-измерения в другие миры запрещены, `/time`, `/weather`, `/gamerule` меняют
только этот мир.

## Администратор сервера

`/pw admin limit <ник> <размер>` — поднять игроку лимит границы; `/pw admin list`, `/pw admin unload <ник>`,
`/pw admin delete <ник>`, `/pw admin reload` (перечитать тексты и пресеты). Операторы сервера могут
заходить в любой мир и имеют в нём права владельца.

## Как защищён основной мир

- Инвентарь, броня, эндер-сундук, слоты Curios, опыт, здоровье, голод, эффекты и режим игры у основного
  мира и у личных миров **раздельные**. Предметы из креатива в выживание не попадают.
- Предметы, мобы, вагонетки и поезда не переходят между личными и основными мирами.
  Порталы в личных мирах не создаются, другие способы телепорта возвращают игрока в точку выхода.
- Командные блоки в личных мирах выключены (`allowCommandBlocks`).
- Точку возрождения в личном мире поставить нельзя. Смерть в личном мире — возрождение там же.
- Из основного мира телепорт с задержкой 3 с (нельзя сбежать из боя).

## Файлы

- `config/personalworlds-common.toml` — лимиты, задержки, списки команд и правил.
- `config/personalworlds/messages.json` — все тексты (цвета через `&`).
- `config/personalworlds/flat_presets.json` — пресеты плоского мира.
- `<мир>/personalworlds/` — данные миров и игроков, `<мир>/dimensions/personalworlds/` — сами миры.

## Сборка и тесты

`./gradlew build` → `build/libs/`. Автотест (`./gradlew runGameTestServer`) проходит весь путь:
создание, обмен инвентаря, права админа, гость, выгрузка/загрузка, перезаход, смерть, пустота, обычный мир.
