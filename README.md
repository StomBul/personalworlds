# Личные миры — гайд для игроков

📖 **Полный гайд с поиском: [stombul.github.io/personalworlds](https://stombul.github.io/personalworlds/)**

## Шпаргалка

| Хочу… | Команда |
|---|---|
| создать свой мир | `/pw create` |
| попасть в свой мир | `/pw home` |
| вернуться в выживание | `/pw leave` |
| зайти к другу | `/pw visit <ник>` |
| попросить доступ к чужому миру | `/pw request <ник>` |
| посмотреть, куда я могу зайти | `/pw list` |
| пустить друга строить | `/pw access add <ник> builder` |
| пустить друга посмотреть | `/pw access add <ник> guest` |
| сделать друга помощником с командами | `/pw role <ник> admin` |
| выгнать игрока из своего мира | `/pw kick <ник>` |
| открыть настройки мира | `/pw setting` |
| поставить точку появления | `/pw setspawn` |
| изменить размер мира | `/pw border <размер>` |
| сменить тип мира (всё удалится) | `/pw reset <тип>` |
| справка прямо в игре | `/pw` |
